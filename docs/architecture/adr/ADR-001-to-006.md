# ADR Index & Core Decisions

- **ADR-001 (Plane Boundary)**: OpenBot 为 Runtime & Governance Plane，AI Optimization 为 Evaluation & Learning Plane；禁止将 AI Optimization 建为 OpenBot 内置插件。
- **ADR-002 (Data Ownership)**: `TaskOutcome` 与生产部署状态权威归 OpenBot；Dataset/Evaluation/Experiment/Artifact 权威归 AI Optimization；严禁双主。
- **ADR-003 (Telemetry Ingestion)**: 全异步非阻塞外发 + 本地有界 WAL（10,000 条 / 64 MiB / 24h TTL）+ `(tenantId, idempotencyKey)` 幂等 + 出站前强制脱敏。
- **ADR-004 (Evaluation Architecture)**: 区分 Rule Evaluator 与 LLM-as-a-Judge；强制绑定 `rubricVersion` 与 `judgeModelVersion`；严格区分 `expert_verified`、`automated_judge`、`user_explicit`、`model_self_eval`。
- **ADR-005 (Artifact Trust)**: SHA-256 完整性 + Ed25519 非对称签名 + `keyId` 轮换 + `expiresAt` + `revocationStatus` + `monotonicEpoch` 防重放，Fail-Closed。
- **ADR-006 (Experiment Statistics)**: 强制随机分流单元、样本量/功效校验（Power >= 0.8）、多重比较校正、护栏早停及防污染检查；离线收益不等同线上收益。
